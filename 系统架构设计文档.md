## 1. 架构设计总览

### 1.1 架构设计目标

本系统架构设计遵循以下核心原则：

1. **模块化**：Python负责AI能力，Java负责工程能力，清晰分层
2. **可扩展**：Agent和Skill可独立扩展，模型配置灵活
3. **可靠性**：支持断点续跑、失败重试、任务追踪
4. **本地优先**：单用户本地运行，不依赖云服务
5. **数据隔离**：项目间完全隔离，避免风格污染

### 1.2 技术栈选型

#### 1.2.1 核心技术栈

**Java后端服务**
- 框架：Spring Boot 3.2+
- 数据库：PostgreSQL 15+（支持pgvector扩展）
- ORM：Spring Data JPA + Hibernate
- API：Spring Web (RESTful)
- 任务队列：Spring Task Executor + 自定义任务管理
- 文件存储：本地文件系统

**Python AI服务**
- 框架：FastAPI（提供REST API）
- Agent编排：LangGraph + 自定义编排器
- LLM客户端：LiteLLM（统一多模型接口）
- 向量检索：LanceDB（本地嵌入式向量数据库）
- 图数据库：NetworkX（纯Python图计算库）+ JSON持久化
- 文本处理：spaCy、jieba
- 重排模型：sentence-transformers

**通信层**
- Java ↔ Python：HTTP REST + JSON
- 异步任务：轮询 + Webhook回调

#### 1.2.2 技术选型理由

**为什么选择Spring Boot：**
- 成熟的企业级框架，生态完善
- 易于实现本地API服务、文件管理、任务调度
- 支持嵌入式数据库，便于本地部署

**为什么选择FastAPI：**
- 高性能异步框架，适合AI推理服务
- 自动生成OpenAPI文档，便于调试
- 类型注解支持，代码清晰

**为什么选择LangGraph：**
- 显式状态管理，适合复杂Agent编排
- 支持循环、条件分支、人工确认节点
- 支持checkpoint和断点续跑

**为什么选择PostgreSQL：**
- 支持pgvector扩展，可直接存储和检索向量
- JSON字段支持，适合存储结构化分析结果
- 本地运行稳定，无需外部依赖

**为什么选择LanceDB：**
- 嵌入式向量数据库，无需额外服务
- 支持大规模向量检索
- 支持过滤和混合检索

**为什么选择NetworkX：**
- 纯Python实现，无额外依赖
- 丰富的图算法支持
- 可序列化为JSON，便于持久化和可视化

#### 2.1.2 核心服务职责

**ProjectService（项目管理服务）**
- 创建项目：生成唯一ID、创建目录结构、初始化元数据
- 查询项目：按ID、状态、创建时间查询
- 更新项目：修改元数据、状态转换
- 删除项目：归档或物理删除（需确认）
- 项目隔离：确保不同项目数据完全隔离

**FileStorageService（文件存储服务）**
- 文件上传：保存原始样本、生成文件指纹
- 文件规范化：统一换行、去除控制字符、检测乱码
- 章节识别：识别章节标题、生成章节边界
- 文件分块：按章节或固定长度分块、生成分块清单
- 覆盖率校验：验证所有文本是否被处理

**TaskExecutor（任务执行服务）**
- 任务创建：生成任务ID、保存初始状态
- 任务调度：根据优先级和资源调度任务
- 任务执行：调用Python服务、监控执行状态
- 任务重试：失败后按策略重试
- 任务取消：支持用户取消长任务
- 断点续跑：保存checkpoint、恢复中断任务

**ModelConfigService（模型配置服务）**
- 配置管理：CRUD操作
- 配置验证：测试连接、验证API Key
- 配置作用域：全局、项目、任务级别
- 降级策略：向量模型、重排模型的回退规则

**SkillLoaderService（Skill加载服务）**
- Skill发现：扫描系统内置Skill、项目专属Skill
- Skill加载：按任务类型加载对应Skill
- Skill路由：根据优先级选择Skill
- 冲突检测：识别并报告Skill冲突

**WorkflowEngine（工作流引擎）**
```python
from langgraph.graph import StateGraph
from typing import Dict, Any, Callable

class WorkflowEngine:
    def __init__(self):
        self.graph = StateGraph()
        
    def add_node(self, name: str, func: Callable):
        """添加工作流节点"""
        self.graph.add_node(name, func)
    
    def add_edge(self, source: str, target: str):
        """添加边"""
        self.graph.add_edge(source, target)
    
    def add_conditional_edge(self, source: str, condition: Callable, edge_map: Dict):
        """添加条件边"""
        self.graph.add_conditional_edges(source, condition, edge_map)
    
    async def run(self, initial_state: Dict[str, Any]) -> Dict[str, Any]:
        """执行工作流"""
        compiled = self.graph.compile()
        return await compiled.ainvoke(initial_state)
```

```markdown
# 项目正文创作规则

## 文笔手法

基于样本拆解，本项目文笔特点：

1. **句式特点**：多用短句，节奏紧凑
2. **段落控制**：单段不超过150字
3. **对话风格**：简洁有力，少用"说道"等标签
4. **场景描写**：先整体后细节，多用感官描写

## 写作技巧

### 战斗场景
- 采用"动作-效果-反应"三段式
- 每次攻击必须有明确结果
- 避免连续多回合没有实质进展

### 日常场景
- 通过对话推进信息
- 适当插入内心独白
- 避免流水账式叙述

### 感情线
- 采用误会-化解-升温模式
- 每次互动必须有微小进展
- 避免突然表白或关系跳跃

## 章节边界控制（核心约束）

**必须遵守规则**：
1. 只完成当前章纲的 must_write 内容
2. 可以轻微铺垫 allowed_progress 内容，但不得完成
3. 严禁写入 must_not_write 内容
4. 严禁提前完成 reserved_for_future 内容
5. 正文必须停在 stop_point 附近

**检查清单**：
- [ ] 本章核心目标是否完成
- [ ] 是否提前解决了后续章节的冲突
- [ ] 是否提前揭晓了后续章节的真相
- [ ] 是否提前完成了后续章节的关系质变
- [ ] 章末是否留有钩子

## 去AI味规则

避免以下AI味表达：
- "深吸一口气"
- "眼中闪过一丝xxx"
- "心中暗道"
- "不禁感叹"
- "这一刻"

替换为自然表达。

## 样本技巧参考

从样本中提取的可迁移技巧：

### 开篇技巧
- 从动作或对话切入，不用环境描写开场

### 章末钩子
- 制造意外转折
- 引入新的威胁或机遇
- 留下未解之谜

### 节奏控制
- 每1000字必须有一个冲突点或信息点
- 避免连续500字纯描写或纯对话
```

### 6.1 混合检索架构

```python
class HybridRetriever:
    def __init__(self, project_id: str):
        self.project_id = project_id
        self.vector_store = VectorStore(f"projects/{project_id}/indexes/vector/")
        self.keyword_index = KeywordIndex(f"projects/{project_id}/indexes/bm25/")
        self.graph = GraphQuery(f"projects/{project_id}/graph/")
    
    async def retrieve(self, query: str, filters: Dict, top_k: int = 20) -> List[Dict]:
        """
        混合检索
        """
        # 1. 向量检索
        query_vector = await self.embed(query)
        vector_results = await self.vector_store.search(
            table_name="knowledge_base",
            query_vector=query_vector,
            top_k=top_k * 2,
            filters=filters
        )
        
        # 2. 关键词检索
        keyword_results = await self.keyword_index.search(
            query=query,
            top_k=top_k * 2,
            filters=filters
        )
        
        # 3. 图谱检索（如果query包含实体）
        entities = await self.extract_entities(query)
        graph_results = []
        if entities:
            for entity in entities:
                neighbors = await self.graph.query_neighbors(
                    node_id=entity,
                    hops=2
                )
                graph_results.extend(neighbors)
        
        # 4. 结果融合
        merged_results = self._merge_results([
            ("vector", vector_results, 0.5),
            ("keyword", keyword_results, 0.3),
            ("graph", graph_results, 0.2)
        ])
        
        # 5. 重排序（如启用）
        if self.reranker:
            reranked_results = await self.reranker.rerank(
                query=query,
                documents=merged_results,
                top_k=top_k
            )
            return reranked_results
        
        return merged_results[:top_k]
```

```python
输出JSON格式。
"""
        relations = await self.llm.extract_relations(relations_prompt)
        
        # 4. 添加关系边
        for relation in relations:
            await self.add_relationship_edge(
                source=relation["source"],
                target=relation["target"],
                relation=RelationType[relation["type"]],
                attributes={
                    "started_chapter": chapter_number,
                    "evidence": relation["evidence"]
                }
            )
        
        # 5. 连接章节节点
        chapter_node = f"chapter_{chapter_number}"
        for entity_id in entities["characters"] + entities["locations"]:
            self.graph.add_edge(
                entity_id,
                chapter_node,
                relation=RelationType.APPEARS_IN.value,
                chapter_number=chapter_number
            )
    
    async def query_character_network(self, character_id: str, hops: int = 2) -> Dict:
        """查询人物关系网络"""
        subgraph = nx.ego_graph(self.graph, character_id, radius=hops)
        
        result = {
            "center": character_id,
            "nodes": [],
            "edges": []
        }
        
        for node in subgraph.nodes(data=True):
            result["nodes"].append({
                "id": node[0],
                "type": node[1].get("type"),
                "name": node[1].get("name"),
                "attributes": node[1]
            })
        
        for edge in subgraph.edges(data=True):
            result["edges"].append({
                "source": edge[0],
                "target": edge[1],
                "relation": edge[2].get("relation"),
                "attributes": edge[2]
            })
        
        return result

        """查找两个角色间的关系路径"""

            return path
        except nx.NetworkXNoPath:
            return []

                previous_status = edge[2].get("previous_status")
                current_status = edge[2].get("status")
                
                if previous_status != current_status:
                    changes.append({
                        "source": edge[0],
                        "target": edge[1],
                        "relation": edge[2].get("relation"),
                        "previous_status": previous_status,
                        "current_status": current_status,
                        "chapter": chapter_number
                    })
        
        return changes

        return output_path
```

```python
class ChunkProcessor:
    def __init__(self, max_workers: int = 3):
        self.max_workers = max_workers
        self.semaphore = asyncio.Semaphore(max_workers)
    
    async def process_chunks_parallel(self, chunks: List[Dict], 
                                     processor_func: Callable) -> List[Dict]:
        """并行处理分块"""
        
        async def process_with_semaphore(chunk):
            async with self.semaphore:
                return await processor_func(chunk)
        
        tasks = [process_with_semaphore(chunk) for chunk in chunks]
        results = await asyncio.gather(*tasks, return_exceptions=True)
        
        # 处理异常
        successful_results = []
        failed_chunks = []
        
        for i, result in enumerate(results):
            if isinstance(result, Exception):
                failed_chunks.append({
                    "chunk_id": chunks[i]["id"],
                    "error": str(result)
                })
            else:
                successful_results.append(result)
        
        return {
            "successful": successful_results,
```

```python
            await asyncio.sleep(0.1)  # 避免过载
    
    async def create_index_with_params(self, table_name: str):
        """创建优化的索引"""
        # LanceDB支持IVF索引加速检索
        await self.vector_store.create_ivf_index(
            table_name=table_name,
            num_partitions=256,  # 根据数据量调整
            num_sub_vectors=96
        )
```

```python
    async def load_checkpoint(self, checkpoint_id: str) -> Dict:
        """加载checkpoint"""
        # 从checkpoint_id提取project_id
        checkpoint_path = await self._find_checkpoint_path(checkpoint_id)
        
        async with aiofiles.open(checkpoint_path, 'r') as f:
            checkpoint_data = json.loads(await f.read())

    async def resume_task(self, task_id: str) -> AgentResult:
        """从checkpoint恢复任务"""
        # 1. 查找最新checkpoint
        latest_checkpoint = await self._find_latest_checkpoint(task_id)
        
        if not latest_checkpoint:
            raise ValueError(f"No checkpoint found for task {task_id}")
        
        # 2. 加载状态
        state = await self.load_checkpoint(latest_checkpoint)
        
        # 3. 获取对应Agent
        agent = self.agent_factory.create_agent(state["agent_name"])
        
        # 4. 继续执行
        result = await agent.run(AgentRequest(
            task_id=task_id,
            resume_from_checkpoint=latest_checkpoint,
            **state["request_params"]
        ))
        
        return result
```

### 13.3 覆盖率校验与修复

```python
class CoverageValidator:
    async def validate_coverage(self, project_id: str, sample_id: str) -> Dict:
        """验证样本覆盖率"""
        sample = await self.load_sample(project_id, sample_id)
        chunks = await self.load_chunks(project_id, sample_id)
        
        total_chars = sample["total_chars"]
        processed_chars = 0
        missing_ranges = []
        
        # 排序chunks
        chunks_sorted = sorted(chunks, key=lambda x: x["start_offset"])
        
        # 检查覆盖
        expected_offset = 0
        for chunk in chunks_sorted:
            if chunk["start_offset"] > expected_offset:
                missing_ranges.append({
                    "start_offset": expected_offset,
                    "end_offset": chunk["start_offset"]
                })
            
            processed_chars += chunk["char_count"]
            expected_offset = chunk["end_offset"]
        
        # 检查结尾
        if expected_offset < total_chars:
            missing_ranges.append({
                "start_offset": expected_offset,
                "end_offset": total_chars
            })
        
        coverage_ratio = processed_chars / total_chars if total_chars > 0 else 0
        
        return {
            "sample_id": sample_id,
            "total_chars": total_chars,
            "processed_chars": processed_chars,
            "coverage_ratio": coverage_ratio,
            "is_complete": coverage_ratio >= 0.999,  # 允许0.1%误差
            "missing_ranges": missing_ranges
        }
    
    async def repair_coverage(self, project_id: str, sample_id: str):
        """修复覆盖率缺失"""
        validation = await self.validate_coverage(project_id, sample_id)
        
        if validation["is_complete"]:
            return {"status": "no_repair_needed"}
        
        # 为缺失区间生成补充chunks
        sample_text = await self.load_sample_text(project_id, sample_id)
        
        new_chunks = []
        for missing_range in validation["missing_ranges"]:
            chunk_text = sample_text[
                missing_range["start_offset"]:missing_range["end_offset"]
            ]
            
            chunk = {
                "id": f"chunk_repair_{len(new_chunks)}",
                "sample_id": sample_id,
                "start_offset": missing_range["start_offset"],
                "end_offset": missing_range["end_offset"],
                "char_count": len(chunk_text),
                "text": chunk_text,
                "is_repair": True
            }
            new_chunks.append(chunk)
        
        # 保存补充chunks
        await self.save_chunks(project_id, new_chunks)
        
        # 对补充chunks执行分析
        for chunk in new_chunks:
            await self.analyze_chunk(project_id, chunk)
        
        return {
            "status": "repaired",
            "new_chunks_count": len(new_chunks)
        }
```
