## 补充1: 模式清晰定义（轻量模式vs增强模式）

### 架构分层模式对比

**标准模式（我们已实现）**
- Java: Spring Boot + PostgreSQL
- Python: FastAPI + LangGraph
- 向量库: LanceDB
- 图数据库: NetworkX + JSON

**可选降级方案**
- 数据库: 可降级为SQLite（单用户场景）
- Agent编排: 可降级为自研简单编排（不依赖LangGraph）
- 向量检索: 可降级为BM25关键词检索
- 重排: 可降级为规则重排

### 适配层设计原则

所有可选依赖必须通过适配层判断：

```python
# 适配层示例
class VectorSearchAdapter:
    def __init__(self):
        self.backend = self._detect_backend()
    
    def _detect_backend(self):
        try:
            import lancedb
            return "lancedb"
        except ImportError:
            return "bm25_fallback"
    
    async def search(self, query: str, top_k: int):
        if self.backend == "lancedb":
            return await self._search_lancedb(query, top_k)
        else:
            return await self._search_bm25(query, top_k)
```

## 补充3: 覆盖率校验机制详细设计

### CoverageChecker实现

```python
class CoverageChecker:
    """覆盖率校验器 - 确保100%文本被处理"""
    
    def validate(self, book_id: str, normalized_text: str,
                chunks: List[Chunk]) -> CoverageReport:
        """
        校验覆盖率
        
        Returns:
            CoverageReport {
                book_id: str
                total_chars: int
                processed_chars: int
                coverage_ratio: float
                missing_ranges: [(start, end), ...]
                failed_chunks: [chunk_id, ...]
                is_complete: bool
            }
        """
        total_chars = len(normalized_text)
        
        # 合并所有chunk覆盖区间
        covered_ranges = []
        failed_chunks = []
        
        for chunk in chunks:
            if chunk.status == "analyzed":
                covered_ranges.append((chunk.start_offset, chunk.end_offset))
            else:
                failed_chunks.append(chunk.id)
        
        # 合并重叠区间
        merged_ranges = self._merge_ranges(covered_ranges)
        
        # 计算处理字符数
        processed_chars = sum(end - start for start, end in merged_ranges)
        
        # 找出缺失区间
        missing_ranges = self._find_gaps(merged_ranges, total_chars)
        
        coverage_ratio = processed_chars / total_chars if total_chars > 0 else 0
        
        return CoverageReport(
            book_id=book_id,
            total_chars=total_chars,
            processed_chars=processed_chars,
            coverage_ratio=coverage_ratio,
            missing_ranges=missing_ranges,
            failed_chunks=failed_chunks,
            is_complete=(coverage_ratio >= 0.999 and not failed_chunks)
        )
    
    def _merge_ranges(self, ranges: List[Tuple[int, int]]) -> List[Tuple[int, int]]:
        """合并重叠区间"""
        if not ranges:
            return []
        
        sorted_ranges = sorted(ranges)
        merged = [sorted_ranges[0]]
        
        for start, end in sorted_ranges[1:]:
            last_start, last_end = merged[-1]
            if start <= last_end:
                # 有重叠，合并
                merged[-1] = (last_start, max(last_end, end))
            else:
                merged.append((start, end))
        
        return merged
    
    def _find_gaps(self, covered: List[Tuple[int, int]], 
                   total: int) -> List[Tuple[int, int]]:
        """找出未覆盖区间"""
        gaps = []
        expected = 0
        
        for start, end in covered:
            if start > expected:
                gaps.append((expected, start))
            expected = max(expected, end)
        
        if expected < total:
            gaps.append((expected, total))
        
        return gaps
```

### 覆盖率强制规则

1. **分析任务必须100%覆盖**: `coverage_ratio` 必须 >= 0.999
2. **有缺口禁止标记完成**: `missing_ranges` 非空时任务失败
3. **有失败块禁止继续**: `failed_chunks` 非空时必须修复
4. **修复机制**: 为缺失区间生成补充chunk并重新分析

```markdown
# 项目正文创作规则

## 适用范围

- 适用任务类型: chapter_writing, chapter_revision
- 适用项目: 当前项目
- 优先级: 高于系统内置规则

## 输入来源

本Skill基于以下分析结果生成：

1. 3本同作者样本的全文拆解
2. 作者风格归纳报告
3. 类型规律归纳报告
4. 1245个可迁移技巧

## 必须使用的规则

### 1. 文笔特征

**句式控制**
- 短句为主，单句不超过30字
- 长短句交替，避免连续3句以上同长度
- 对话句占比30%-40%

**段落控制**
- 单段不超过150字
- 对话段独立成段
- 场景切换必须换段

**描写风格**
- 动作描写：动词具体化，避免"走过去"
- 场景描写：先整体后细节，多用感官
- 心理描写：少用"心想"，多用行为暗示

### 2. 结构技巧

**章节开头**
- 不用环境描写开场
- 从动作或对话切入
- 前3句必须有信息量或冲突

**章节结尾**
- 必须有钩子
- 钩子类型：意外转折 / 新威胁 / 未解之谜
- 不用"且听下回分解"等俗套

**节奏控制**
- 每1000字必须有一个冲突点或信息点
- 避免连续500字纯描写或纯对话
- 战斗场景每200字必须有实质进展

### 3. 爽点设计

**突破爽点**
- 必须有铺垫（至少前2章埋设）
- 必须有见证者反应
- 必须有实力对比

**打脸爽点**
- 先抑后扬
- 反转要合理
- 避免降智配角

## 必须避免的问题

### 1. AI味表达

**禁用词汇**
- "深吸一口气"
- "眼中闪过一丝xxx"
- "心中暗道"
- "不禁感叹"
- "这一刻"

**替换方案**
- 用行为替代心理描写
- 用对话替代叙述
- 用细节替代形容词

### 2. 复刻风险

**禁止直接复用**
- 样本中的专有名词
- 样本中的人物关系设定
- 样本中的具体情节
- 样本中超过15字的原文

**允许迁移**
- 结构模式
- 技巧手法
- 节奏安排
- 爽点类型

## 章节边界控制（核心约束）

### 边界原则

1. **只完成本章must_write内容**
2. **可轻微铺垫allowed_progress，但不得完成**
3. **严禁写入must_not_write内容**
4. **严禁提前完成reserved_for_future内容**
5. **正文必须停在stop_point附近**

### 检查清单

在生成正文前，必须明确：

- [ ] 本章核心目标是什么
- [ ] 哪些是后续章节的内容
- [ ] 章末应该停在哪里
- [ ] 是否提前解决了后续冲突
- [ ] 是否提前揭晓了后续真相

### 越界示例

**错误示例**
```

```python
class SkillConflictDetector:
```

### 边界检查算法

```python
class BoundaryChecker:
    def check_violation(self, chapter_content: str,
                       boundary_control: Dict) -> List[Violation]:
        violations = []
        
        # 检查must_not_write
        for forbidden in boundary_control["must_not_write"]:
            if self._content_contains_event(chapter_content, forbidden):
                violations.append(Violation(
                    severity="error",
                    type="forbidden_content",
                    message=f"章节包含禁止内容：{forbidden}",
                    suggestion="删除该情节，移至后续章节"
                ))
        
        # 检查reserved_for_future
        for future_chapter, future_content in boundary_control["reserved_for_future"].items():
            if self._content_contains_event(chapter_content, future_content):
                violations.append(Violation(
                    severity="error",
                    type="future_content_violation",
                    message=f"提前完成了{future_chapter}的内容：{future_content}",
                    suggestion=f"将该情节保留给{future_chapter}"
                ))
        
        # 检查must_write完成度
        completed_goals = []
        for goal in boundary_control["must_write"]:
            if self._content_contains_event(chapter_content, goal):
                completed_goals.append(goal)
        
        if len(completed_goals) < len(boundary_control["must_write"]):
            missing = set(boundary_control["must_write"]) - set(completed_goals)
            violations.append(Violation(
                severity="warning",
                type="incomplete_goals",
                message=f"本章目标未完成：{', '.join(missing)}",
                suggestion="补充缺失的核心情节"
            ))
        
        return violations
```

```python
class ModelGateway:
    """
    模型网关 - 统一管理所有LLM调用
    
    职责：
    1. 路由到正确的模型
    2. 统一重试策略
    3. 统一错误处理
    4. 统一Token计数
    5. 统一缓存策略
    6. 统一降级策略
    """
    
    def __init__(self):
        self.providers = {}
        self.cache = ModelCache()
        self.fallback_chain = []
    
    def register_provider(self, name: str, provider: ModelProvider):
        """注册模型提供商"""
        self.providers[name] = provider
    
    async def complete(self, 
                      prompt: str,
                      model_config: ModelConfig,
                      **kwargs) -> ModelResponse:
        """
        统一的完成接口
        
        流程：
        1. 检查缓存
        2. 选择模型
        3. 调用模型
        4. 重试（如需要）
        5. 降级（如失败）
        6. 记录指标
        7. 更新缓存
        """
        # 1. 检查缓存
        cache_key = self._build_cache_key(prompt, model_config)
        if cached := await self.cache.get(cache_key):
            return cached
        
        # 2. 准备调用
        provider_name = model_config.provider
        model_name = model_config.model
        
        # 3. 调用主模型
        try:
            response = await self._call_with_retry(
                provider_name,
                model_name,
                prompt,
                **kwargs
            )
            
            # 7. 更新缓存
            await self.cache.set(cache_key, response)
            
            return response
            
        except Exception as e:
            # 5. 降级处理
            if self.fallback_chain:
                return await self._try_fallback(prompt, **kwargs)
            raise
    
    async def _call_with_retry(self, provider: str, model: str,
                              prompt: str, max_retries: int = 3,
                              **kwargs) -> ModelResponse:
        """带重试的调用"""
        for attempt in range(max_retries):
            try:
                provider_instance = self.providers[provider]
                response = await provider_instance.complete(
                    model=model,
                    prompt=prompt,
                    **kwargs
                )
                
                # 记录成功指标
                self._record_metrics("success", provider, model, response)
                
                return response
                
            except RateLimitError as e:
                # 速率限制 - 等待后重试
                wait_time = 2 ** attempt
                await asyncio.sleep(wait_time)
                
            except NetworkError as e:
                # 网络错误 - 立即重试
                if attempt == max_retries - 1:
                    raise
                    
            except Exception as e:
                # 其他错误 - 不重试
                self._record_metrics("error", provider, model, e)
                raise
    
    async def _try_fallback(self, prompt: str, **kwargs) -> ModelResponse:
        """尝试降级模型"""
        for fallback_config in self.fallback_chain:
            try:
                return await self.complete(prompt, fallback_config, **kwargs)
            except Exception:
                continue
        
        raise Exception("All models failed, including fallbacks")
    
    def _build_cache_key(self, prompt: str, config: ModelConfig) -> str:
        """构建缓存键"""
        import hashlib
        content = f"{prompt}:{config.model}:{config.temperature}"
        return hashlib.md5(content.encode()).hexdigest()
```

```python
class RetrievalEngine:
    """
    混合检索引擎
    
    整合：
    1. 向量检索（语义相似）
    2. 关键词检索（精确匹配）
    3. 图谱检索（关系推理）
    4. 重排序（相关性优化）
    """
    
    def __init__(self, project_id: str):
        self.project_id = project_id
        self.vector_store = VectorStore(project_id)
        self.keyword_index = KeywordIndex(project_id)
        self.graph_query = GraphQuery(project_id)
        self.reranker = Reranker(project_id)
    
    async def retrieve(self,
                      query: str,
                      retrieval_plan: RetrievalPlan,
                      top_k: int = 20) -> List[Document]:
        """
        执行混合检索
        
        Args:
            query: 检索查询
            retrieval_plan: 检索计划（指定使用哪些检索器）
            top_k: 返回数量
        
        Returns:
            排序后的文档列表
        """
        results = []
        
        # 1. 向量检索
        if retrieval_plan.use_vector:
            vector_results = await self.vector_store.search(
                query=query,
                top_k=top_k * 2,
                filters=retrieval_plan.vector_filters
            )
            results.extend(self._tag_source(vector_results, "vector"))
        
        # 2. 关键词检索
        if retrieval_plan.use_keyword:
            keyword_results = await self.keyword_index.search(
                query=query,
                top_k=top_k * 2,
                filters=retrieval_plan.keyword_filters
            )
            results.extend(self._tag_source(keyword_results, "keyword"))
        
        # 3. 图谱检索
        if retrieval_plan.use_graph:
            # 提取实体
            entities = await self._extract_entities(query)
            for entity in entities:
                graph_results = await self.graph_query.query_neighbors(
                    node_id=entity,
                    relation=retrieval_plan.graph_relation,
                    hops=retrieval_plan.graph_hops
                )
                results.extend(self._tag_source(graph_results, "graph"))
        
        # 4. 去重
        unique_results = self._deduplicate(results)
        
        # 5. 重排序
        if retrieval_plan.use_rerank and self.reranker:
            ranked_results = await self.reranker.rerank(
                query=query,
                documents=unique_results,
                top_k=top_k
            )
            return ranked_results
        
        # 6. 融合排序
        return self._fusion_rank(unique_results, top_k)
    
    def _fusion_rank(self, results: List[Document], 
                    top_k: int) -> List[Document]:
        """
        融合排序算法（RRF - Reciprocal Rank Fusion）
        
        Score = Σ(1 / (k + rank_i))
        k = 60 (常用值)
        """
        k = 60
        doc_scores = {}
        
        for doc in results:
            doc_id = doc.id
            source_rank = doc.metadata.get("rank", 0)
            
            if doc_id not in doc_scores:
                doc_scores[doc_id] = {
                    "doc": doc,
                    "score": 0.0
                }
            
            doc_scores[doc_id]["score"] += 1.0 / (k + source_rank)
        
        # 按分数排序
        ranked = sorted(
            doc_scores.values(),
            key=lambda x: x["score"],
            reverse=True
        )
        
        return [item["doc"] for item in ranked[:top_k]]
    
    def _deduplicate(self, results: List[Document]) -> List[Document]:
        """去重"""
        seen = set()
        unique = []
        
        for doc in results:
            if doc.id not in seen:
                seen.add(doc.id)
                unique.append(doc)
        
        return unique
```

### 工作流引擎实现

```python
class WorkflowEngine:
    """工作流编排引擎"""
    
    def __init__(self):
        self.agent_registry = {}
        self.function_registry = {}
    
    async def execute_workflow(self,
                               workflow_def: Dict,
                               initial_input: Dict) -> WorkflowResult:
        """
        执行工作流
        
        Args:
            workflow_def: 工作流定义
            initial_input: 初始输入
        
        Returns:
            WorkflowResult包含所有节点的输出
        """
        context = WorkflowContext(
            workflow_id=workflow_def["workflow_id"],
            input=initial_input,
            outputs={}
        )
        
        # 构建执行图
        graph = self._build_graph(workflow_def)
        
        # 拓扑排序
        execution_order = self._topological_sort(graph)
        
        # 依次执行节点
        for node_id in execution_order:
            node_def = workflow_def["nodes"][node_id]
            
            try:
                result = await self._execute_node(node_def, context)
                context.outputs[node_id] = result
                
                # 保存checkpoint
                await self._save_checkpoint(context)
                
            except Exception as e:
                # 错误处理
                if node_def.get("on_error") == "continue":
                    context.outputs[node_id] = {"error": str(e)}
                else:
                    raise
        
        return WorkflowResult(
            workflow_id=context.workflow_id,
            status="success",
            outputs=context.outputs
        )
    
    async def _execute_node(self, node_def: Dict,
                           context: WorkflowContext) -> Any:
        """执行单个节点"""
        node_type = node_def["type"]
        
        if node_type == "agent":
            return await self._execute_agent_node(node_def, context)
        elif node_type == "agent_loop":
            return await self._execute_loop_node(node_def, context)
        elif node_type == "function":
            return await self._execute_function_node(node_def, context)
        elif node_type == "conditional":
            return await self._execute_conditional_node(node_def, context)
        else:
            raise ValueError(f"Unknown node type: {node_type}")
    
    async def _execute_agent_node(self, node_def: Dict,
                                  context: WorkflowContext) -> Any:
        """执行Agent节点"""
        agent_name = node_def["agent"]
        agent = self.agent_registry[agent_name]
        
        # 解析输入（支持表达式）
        input_data = self._resolve_input(node_def["input"], context)
        
        # 调用Agent
        request = AgentRequest(
            task_id=f"{context.workflow_id}_{node_def['id']}",
            **input_data
        )
        
        response = await agent.run(request)
        
        return response
    
    async def _execute_loop_node(self, node_def: Dict,
                                 context: WorkflowContext) -> List[Any]:
        """执行循环节点（支持并行）"""
        loop_items = self._resolve_expression(node_def["loop_over"], context)
        parallel = node_def.get("parallel", 1)
        
        results = []
        
        if parallel > 1:
            # 并行执行
            semaphore = asyncio.Semaphore(parallel)
            
            async def process_item(item):
                async with semaphore:
                    item_context = context.copy()
                    item_context.current_item = item
                    return await self._execute_agent_node(node_def, item_context)
            
            tasks = [process_item(item) for item in loop_items]
            results = await asyncio.gather(*tasks)
        else:
            # 串行执行
            for item in loop_items:
                item_context = context.copy()
                item_context.current_item = item
                result = await self._execute_agent_node(node_def, item_context)
                results.append(result)
                
                # checkpoint
                if len(results) % node_def.get("checkpoint_interval", 10) == 0:
                    await self._save_checkpoint(context, results)
        
        return results
    
    def _resolve_expression(self, expr: str, context: WorkflowContext) -> Any:
        """解析表达式，如 ${import.output.chunks}"""
        if not expr.startswith("${") or not expr.endswith("}"):
            return expr
        
        path = expr[2:-1]  # 去掉 ${ 和 }
        
        # 解析路径
        parts = path.split(".")
        
        value = context
        for part in parts:
            if part == "input":
                value = context.input
            elif part == "item":
                value = context.current_item
            elif part == "output":
                continue
            else:
                value = value.get(part)
                if value is None:
                    raise ValueError(f"Cannot resolve expression: {expr}")
        
        return value
```

```python
    async def ingest_chapter(self, chapter_number: int,
                            chapter_content: str) -> IngestResult:
        """
        摄取章节记忆
        
        这是记忆系统的核心入口，在章节终稿后调用
        """
        result = IngestResult(chapter_number=chapter_number)
        
        # 1. 生成章节摘要
        summary = await self._generate_summary(chapter_content)
        result.summary = summary
        
        # 2. 提取实体和事件
        entities = await self._extract_entities(chapter_content)
        events = await self._extract_events(chapter_content)
        
        # 3. 更新人物记忆
        for character in entities["characters"]:
            updates = await self.character_memory.update_from_chapter(
                character=character,
                chapter_number=chapter_number,
                chapter_content=chapter_content
            )
            result.character_updates.append(updates)
        
        # 4. 更新伏笔记忆
        foreshadowing_mentions = await self._detect_foreshadowing_mentions(
            chapter_content
        )
        for mention in foreshadowing_mentions:
            update = await self.foreshadowing_memory.advance(
                foreshadowing_id=mention["id"],
                chapter_number=chapter_number,
                progress_description=mention["progress"]
            )
            result.foreshadowing_updates.append(update)
        
        # 5. 更新时间线
        for event in events:
            await self.timeline_memory.add_event(
                chapter_number=chapter_number,
                event=event
            )
        result.timeline_events = events
        
        # 6. 更新人物关系
        relationship_changes = await self._extract_relationship_changes(
            chapter_content,
            entities["characters"]
        )
        for change in relationship_changes:
            await self.relationship_memory.update(change)
        result.relationship_changes = relationship_changes
        
        # 7. 更新认知状态
        cognition_updates = await self._extract_cognition_updates(
            chapter_content,
            entities["characters"]
        )
        for update in cognition_updates:
            await self.cognition_memory.update(update)
        result.cognition_updates = cognition_updates
        
        # 8. 识别Canon候选
        canon_candidates = await self._identify_canon_candidates(
            chapter_content,
            chapter_number
        )
        for candidate in canon_candidates:
            await self.canon_memory.add_candidate(candidate)
        result.canon_candidates = canon_candidates
        
        # 9. 保存章节快照
        snapshot = self._build_snapshot(
            chapter_number=chapter_number,
            summary=summary,
            entities=entities,
            events=events,
            result=result
        )
        await self._save_snapshot(snapshot)
        
        return result
    
    async def query_active_characters(self) -> List[CharacterState]:
        """查询当前活跃的人物"""
        return await self.character_memory.query_active()
    
    async def query_active_foreshadowing(self) -> List[ForeshadowingState]:
        """查询当前活跃的伏笔"""
        return await self.foreshadowing_memory.query_active()
    
    async def get_character_state(self, character_name: str) -> CharacterState:
        """获取人物当前状态"""
        return await self.character_memory.get_state(character_name)
    
    async def get_cognition_matrix(self, 
                                  characters: List[str]) -> CognitionMatrix:
        """
        获取认知矩阵
```

```python
class ForeshadowingMemory:
    """伏笔记忆管理"""
    
    def __init__(self, memory_path: str):
        self.memory_file = Path(memory_path) / "foreshadowing.md"
        self.foreshadowings = []
        self._load()
    
    def _load(self):
        """加载伏笔记忆文件"""
        if not self.memory_file.exists():
            return
        
        # 解析Markdown文件，提取所有伏笔
        content = self.memory_file.read_text(encoding="utf-8")
        self.foreshadowings = self._parse_foreshadowings(content)
    
    async def add(self, foreshadowing: Foreshadowing):
        """添加新伏笔"""
        self.foreshadowings.append(foreshadowing)
        await self._save()
    
    async def advance(self, foreshadowing_id: str,
                     chapter_number: int,
                     progress_description: str) -> ForeshadowingUpdate:
        """推进伏笔"""
        fs = self._find_by_id(foreshadowing_id)
        
        if not fs:
            raise ValueError(f"Foreshadowing not found: {foreshadowing_id}")
        
        # 更新状态
        fs.last_advanced_chapter = chapter_number
        fs.status = "advanced"
        fs.advance_history.append({
            "chapter": chapter_number,
            "description": progress_description
        })
        
        # 计算债务评分
        fs.debt_score = self._calculate_debt_score(fs, chapter_number)
        
        await self._save()
        
        return ForeshadowingUpdate(
            foreshadowing_id=foreshadowing_id,
            action="advanced",
            chapter=chapter_number
        )
    
    async def payoff(self, foreshadowing_id: str,
                    chapter_number: int,
                    payoff_description: str):
        """回收伏笔"""
        fs = self._find_by_id(foreshadowing_id)
        
        if not fs:
            raise ValueError(f"Foreshadowing not found: {foreshadowing_id}")
        
        fs.status = "paid_off"
        fs.payoff_chapter = chapter_number
        fs.payoff_description = payoff_description
        
        await self._save()
    
    async def query_active(self) -> List[Foreshadowing]:
        """查询活跃伏笔（已埋设但未回收）"""
        return [
            fs for fs in self.foreshadowings
            if fs.status in ["planted", "advanced"]
        ]
    
    async def query_high_debt(self, 
                             current_chapter: int,
                             threshold: float = 0.6) -> List[Foreshadowing]:
        """查询高债务伏笔（急需推进或回收）"""
        high_debt = []
        
        for fs in self.foreshadowings:
            if fs.status in ["planted", "advanced"]:
                debt = self._calculate_debt_score(fs, current_chapter)
                if debt >= threshold:
                    fs.debt_score = debt
                    high_debt.append(fs)
        
        return sorted(high_debt, key=lambda x: x.debt_score, reverse=True)
    
    def _calculate_debt_score(self, fs: Foreshadowing,
                             current_chapter: int) -> float:
        """
        计算伏笔债务评分
        
        考虑因素：
        1. 埋设后经过的章节数
        2. 最后推进后经过的章节数
        3. 是否接近预期回收范围
        4. 伏笔类型权重
        """
        # 1. 埋设时间
        chapters_since_planted = current_chapter - fs.planted_chapter
        time_score = chapters_since_planted * 0.02
        
        # 2. 未推进时间
        last_advanced = fs.last_advanced_chapter or fs.planted_chapter
        chapters_since_advanced = current_chapter - last_advanced
        stale_score = chapters_since_advanced * 0.05
        
        # 3. 接近回收期
        payoff_urgency = 0.0
        if fs.expected_payoff_range:
            start = fs.expected_payoff_range["start"]
            if current_chapter >= start:
                payoff_urgency = 1.0
            elif current_chapter >= start - 5:
                payoff_urgency = 0.5
        
        # 4. 类型权重
        type_weights = {
            "main": 1.5,
            "subplot": 1.2,
            "character": 1.0,
            "normal": 1.0
        }
        type_weight = type_weights.get(fs.type, 1.0)
        
        # 综合评分
        debt = (time_score + stale_score + payoff_urgency * 0.3) * type_weight
        
        return min(debt, 1.0)
    
    async def _save(self):
        """保存到Markdown文件"""
        content = self._format_as_markdown()
        self.memory_file.write_text(content, encoding="utf-8")
    
    def _format_as_markdown(self) -> str:
        """格式化为Markdown"""
        lines = ["# 伏笔记忆\n\n"]
        
        for fs in self.foreshadowings:
            lines.append(f"## {fs.name}\n\n")
            lines.append(f"**ID**: {fs.id}\n")
            lines.append(f"**状态**: {fs.status}\n")
            lines.append(f"**埋设章节**: 第{fs.planted_chapter}章\n")
            
            if fs.last_advanced_chapter:
                lines.append(f"**最后推进**: 第{fs.last_advanced_chapter}章\n")
            
            if fs.expected_payoff_range:
                start = fs.expected_payoff_range["start"]
                end = fs.expected_payoff_range["end"]
                lines.append(f"**预计回收**: 第{start}-{end}章\n")
            
            lines.append(f"\n**描述**\n{fs.description}\n\n")
            
            if fs.advance_history:
                lines.append("**推进历史**\n")
                for record in fs.advance_history:
                    lines.append(f"- 第{record['chapter']}章: {record['description']}\n")
                lines.append("\n")
            
            if fs.related_entities:
                lines.append(f"**关联实体**: {', '.join(fs.related_entities)}\n\n")
            
            if fs.debt_score:
                lines.append(f"**债务评分**: {fs.debt_score:.2f}\n\n")
            
            lines.append("---\n\n")
        
        return "".join(lines)
```

```python
class CognitionMemory:
    """
    认知记忆 - 追踪角色的认知状态
    
    谁知道什么，谁不知道什么，谁误解了什么
    """
    
    def __init__(self, memory_path: str):
        self.memory_file = Path(memory_path) / "cognition.md"
        self.cognition_states = {}
        self._load()
    
    async def update(self, update: CognitionUpdate):
        """
        更新认知状态
        
        Args:
            update: {
                "character": "张三",
                "chapter": 5,
                "type": "knows" | "does_not_know" | "misunderstands",
                "fact_id": "神器在北山",
                "fact_description": "神器真正位置在北山洞窟",
                "evidence": "第5章1200字处"
            }
        """
        character = update["character"]
        
        if character not in self.cognition_states:
            self.cognition_states[character] = {
                "knows": [],
                "does_not_know": [],
                "misunderstands": []
            }
        
        cognition_type = update["type"]
        fact = {
            "fact_id": update["fact_id"],
            "description": update["fact_description"],
            "since_chapter": update["chapter"],
            "evidence": update.get("evidence", "")
        }
        
        # 添加到对应列表
        self.cognition_states[character][cognition_type].append(fact)
        
        await self._save()
    
    async def build_matrix(self, characters: List[str]) -> CognitionMatrix:
        """
        构建认知矩阵
        
        Returns:
            {
                "张三": {
                    "knows": ["神器在北山", "李四是叛徒"],
                    "does_not_know": ["王五已突破"],
                    "misunderstands": ["以为神器无主"]
                },
                "李四": {...}
            }
        """
        matrix = {}
        
        for character in characters:
            if character in self.cognition_states:
                matrix[character] = self.cognition_states[character]
            else:
                matrix[character] = {
                    "knows": [],
                    "does_not_know": [],
                    "misunderstands": []
                }
        
        return matrix
    
    async def check_inconsistency(self, 
                                 character: str,
                                 action: str) -> List[Inconsistency]:
        """
        检查行为与认知的一致性
        
        如果角色做了某个行为，但认知状态显示他不应该知道，则报告不一致
        """
        inconsistencies = []
        
        # 检查角色是否知道执行该行为所需的信息
        required_knowledge = self._infer_required_knowledge(action)
        
        for fact in required_knowledge:
            if not self._character_knows(character, fact):
                inconsistencies.append(Inconsistency(
                    character=character,
                    action=action,
                    missing_knowledge=fact,
                    severity="error",
                    message=f"{character}不应该知道{fact}，但却执行了需要该知识的行为"
                ))
        
        return inconsistencies
```
